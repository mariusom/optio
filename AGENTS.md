# Contributor guidance

- Before changing app logic or storage, read [architecture](docs/architecture.md)
  for ownership, timestamp rules and persistence constraints.
- Before changing UI, read [interface conventions](docs/interface.md).
- Before changing agent tools, consent or transports, read
  [agent access](docs/agent-access.md), especially asynchronous writes and approval.
- For setup, verification and dependency updates, follow
  [development](docs/development.md). Keep technical documentation there and the
  README focused on what the app does.
- `CLAUDE.md` is a symlink to this file; maintain one set of instructions.
