Optio third-party notices
=========================

This file records third-party source copied or adapted into Optio, and patched
dependencies. It is included in full in the generated THIRD_PARTY_NOTICES.txt,
which also appends installed package license and NOTICE files;
dependency-inventory.json records their hashes and scope.


Foldcn registry components and generated style data
----------------------------------------------------

Portions of src/components/ui and the style data in
src/web/componentStyles.generated.ts are copied or adapted from Foldcn registry
modules. Optio's copies have been translated to FoldKit builders and locally
modified. The generated table contains class strings retrieved from 18 Foldcn
registry modules in the Nova, Vega, Maia, Lyra, Mira, Luma, Sera, and Rhea
styles on 2026-09-09.

Source: https://github.com/elianiva/foldcn
Registry: https://foldcn.elianiva.com/r/
Revision: the registry URLs were not pinned when the source and style data were
retrieved. The contemporaneous Foldcn repository revision on 2026-09-09 was
f6e30394d038590fd3911d608ea3e46a57de20b0. This identifies the best verifiable
upstream snapshot, not a claim that the registry server guaranteed that commit.

Patched dependencies
--------------------

@livestore/adapter-web (Apache-2.0) is installed with
patches/@livestore__adapter-web@0.5.0-dev.0.patch, which adds
`codecFor: Schema.toCodecJson` to the worker RPC protocol. The patch marks the
changed lines with a "Modified by Optio" notice in the package source and dist
files, and that notice survives in the distributed worker bundle. See
docs/development.md for why the patch exists and when it can be removed.
