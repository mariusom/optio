# Code of conduct

Optio welcomes people with different backgrounds and experience. Treat each
other respectfully in issues, pull requests and other project spaces.

- Critique code and ideas, not people. Give constructive, specific feedback.
- Respect privacy, authorship and licenses. Ask before sharing another person's
  data or private messages.
- Do not harass, threaten, discriminate, make sexual advances, or repeatedly
  disrupt a discussion. Stop unwanted contact when asked.

The maintainer, [Marius Matei (@mariusom)](https://github.com/mariusom), handles
conduct concerns. Report non-sensitive concerns by mentioning the maintainer
in an issue. If a report needs privacy, request a private contact channel
without posting names, evidence or sensitive details publicly. The project does
not currently advertise a dedicated confidential conduct-reporting inbox.
Security vulnerabilities use the separate [security policy](SECURITY.md).

The maintainer may edit or remove harmful content, close discussions, warn
participants, or restrict participation according to severity and repetition.
Participants may ask the maintainer to reconsider a decision with additional
context. No independent appeals panel or guaranteed response time is promised.
